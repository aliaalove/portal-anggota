CEK STATUS ANGGOTA — DEMO

CARA MENJALANKAN
1. Ekstrak ZIP.
2. Buka folder cek-status-anggota.
3. Klik dua kali index.html untuk membuka demo di browser.
4. Coba nama demo: Ahmad Fauzi, Siti Nurhaliza, Budi Santoso,
   Dewi Anggraini, atau Rizky Pratama.

FILE
- index.html : struktur halaman
- style.css  : tampilan dan responsif mobile
- script.js  : pencarian menggunakan data contoh

PENTING
Demo ini belum terhubung ke data Excel atau database online.
Jangan menambahkan data anggota asli ke script.js karena file JavaScript
yang dipublikasikan dapat dibaca pengunjung.

TAHAP BERIKUTNYA
Untuk data asli, gunakan backend privat (misalnya Google Apps Script yang
dikonfigurasi dengan benar) agar browser hanya menerima hasil pencarian,
bukan seluruh daftar anggota. Pastikan klien menyetujui cara pencarian,
privasi data, dan siapa yang boleh mengakses hasil.
